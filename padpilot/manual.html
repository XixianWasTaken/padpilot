用一只 PS5 手柄，开 ClaudeDrive Claude with a PS5 controller

padpilot 让 DualSense 的光条、震动、扳机和喇叭实时告诉你 agent 在干什么，再用按键批准、中断、选下一步、重发消息。Claude Code、Codex CLI 和 Claude 桌面 app 用同一套按键。padpilot makes the DualSense's lightbar, rumble, triggers and speaker show what the agent is doing, and lets the buttons approve, interrupt, pick the next step and retry. Claude Code, Codex CLI and the Claude desktop app share one button layout.

01开始Getting started

需要一只 DualSense 手柄（USB 或蓝牙）、macOS 和 Python 3.8 或更新的版本。Linux 上终端部分应该能用，但没测过；控制 Claude 桌面 app 只支持 macOS。

You need a DualSense (USB or Bluetooth), macOS, and Python 3.8 or newer. The terminal parts should work on Linux but are untested; driving the Claude desktop app is macOS only.

git clone https://github.com/XixianWasTaken/padpilot.git
cd padpilot
./bin/padpilot setup                              # hidapi → ~/.padpilot/venv
ln -sf "$PWD/bin/padpilot" ~/.local/bin/padpilot

claude plugin marketplace add "$PWD"
claude plugin install padpilot@padpilot

padpilot install-codex   # optional: Codex hooks
padpilot doctor          # hidapi, controller, daemon
padpilot demo            # rainbow + rumble

每天这样用Every day

alias cc='padpilot run claude'   # Claude Code
alias cx='padpilot run codex'    # Codex CLI

padpilot run 把 agent 包在一个看起来和原来一模一样的终端里，手柄按键变成键盘输入。不经过它（IDE、Claude 桌面 app、直接运行的 agent）时，灯光和震动照常工作，审批改由 hook 处理（见第 06 章）。

padpilot run wraps the agent in a terminal that looks and works exactly as before; the buttons become keystrokes. Without it (an IDE, the Claude desktop app, an agent started directly) the light and rumble still work, and approvals go through a hook (chapter 06).

第一次用？先去 手柄驾校 一步一个键练一遍，或在 Claude Code 里输入 /padpilot:tutorial。New here? Learn one button at a time at Pad School, or type /padpilot:tutorial in Claude Code.

扳机和小灯Triggers and the small lights

  • 等批准时：R2 有一段阻力，扣到底“咔”一下 = 批准；L2 有轻阻力。
  • agent 在干活时：L2 有一点阻力，提醒你扣到底 = 中断。
  • 玩家灯平时是本轮进度条：工具调用到 1 / 3 / 6 / 11 / 21 次时各多亮一格。agent 停下、下一步卡片上有回复按钮时，亮几格就是有几个按钮可以选。
  • 麦克风灯亮 = 有 app 在录音，或手柄被锁住了。
  • 按一下 PS：光条显示电量（红到绿），玩家灯显示上下文用了几成。上下文超过 80% 时，完成的绿灯会在绿和琥珀之间慢慢变，提醒你该压缩或开新会话了。
  • Waiting for approval: R2 gets a click point; pull it through = approve. L2 has light resistance.
  • While the agent works: L2 has a little resistance, a reminder that pulling it through = interrupt.
  • The player LEDs are the turn's progress bar: one more at 1 / 3 / 6 / 11 / 21 tool calls. When the agent has stopped with a next-step card, they show how many reply buttons you can pick.
  • The mic LED on = some app is recording, or the controller is locked.
  • Tap PS: the lightbar shows the battery (red to green) and the player LEDs how much context is used. Over 80% context, the done-green fades towards amber: time to compact or start a new session.

03按键Buttons

同一个键在三个程序里做同一件事。每个键对应一个“功能”（提交、取消、清空输入……），按下时换算成那个程序实际用的快捷键，包括你自己在 ~/.claude/keybindings.json 里改过的。某个程序没有这个功能时，什么都不发，光条红闪一下。

A button does the same thing in all three apps. Each one is mapped to an action (submit, cancel, clear input…) and turned into the keys that app uses, including your own ~/.claude/keybindings.json. If an app has no such action, nothing is sent and the light flashes red.

04组合键Combos

R1、L1、PS 是修饰键，像键盘上的 Shift：按住它，再按另一个键。它们自己的短按和长按在松开时才算，用过组合键就不算，所以不会误按出 / 或电量。长按到时间会“嗒”轻震一下，这时松开就是长按。

R1, L1 and PS are modifiers, like Shift: hold one, then press another button. Their own tap and hold count only on release, and not at all once a combo was used, so you never get a stray / or battery display. A hold gives a small tick when it is reached; let go then.

05进阶招式Pro moves

快捷语轮盘：按住 △ + 右摇杆Prompt wheel: hold △ + right stick

按住 △，把右摇杆推向一个方向，松开 △：清空输入框，填进那句话（不发送，你可以再改，按 ✕ 发出）。拨到新方向时轻震一下，光条变成那个方向的颜色。

Hold △, push the right stick one way, let go of △: the input box is cleared and that prompt is filled in (not sent, so you can edit it; ✕ sends). Each new direction gives a small tick and its own lightbar colour.

↖继续修这个 bugkeep fixing this bug
↑继续continue
↗运行测试并修复失败的用例run the tests and fix failures
←总结一下改动summarise the changes
△
→解释一下你刚才做了什么explain what you just did
↙给这部分写测试write tests for this
↓提交代码commit
↘先停下来，问我再继续stop and ask me first

这 8 句可以在设置里的 "prompt_wheel" 改成你自己的。Change the eight prompts with "prompt_wheel" in the settings.

重试：R3Retry: R3

不小心中断了，或者想再跑一遍：按 R3（按下右摇杆），把你上一条消息原样再发一次。桌面 app 里只填进输入框不发送，因为它不告诉我们屏幕上是哪个会话，你看一眼再按 ✕。agent 还在干活时按 R3 会“不行”两下短震；你确定它已经停了（比如用鼠标点了停止），2 秒内再按一次就强制重发。

Interrupted by mistake, or want another run? Press R3 (click the right stick) to send your last message again. In the desktop app it is only filled in, because the app does not say which session is on screen; check it and press ✕. While the agent still works, R3 gives the two-buzz “no”; if you know it has stopped (say you clicked stop with the mouse), press R3 again within 2 seconds to force it.

下一步卡片：R1 + 面键Next-step card: R1 + face button

Claude 桌面 app 在一轮结束时可能给出带按钮的卡片。卡片出现时手柄轻点两下，玩家灯亮出按钮个数。R1 + ✕ 选第 1 个，R1 + ○ 选第 2 个，以此类推，效果和点击一样。“提交 / 建 PR”这类 app 自己处理的按钮只能用鼠标点。

At the end of a turn the Claude desktop app may show a card with reply buttons. The controller taps twice and the player LEDs show how many there are. R1 + ✕ picks the first, R1 + ○ the second, and so on, just like clicking. Buttons the app handles itself, such as commit or create PR, still need the mouse.

按住说话：micHold to talk: mic

在桌面 app 里，麦克风键就是 Claude 自带的听写。短按开始、再按结束；或者按住说话（超过 0.5 秒），松开就停。听写时光条白色快呼吸、麦克风灯亮。

In the desktop app the mic button is Claude's own dictation. Tap to start and tap to stop, or hold it (over 0.5 s) and talk; letting go stops. While dictating, the light breathes white and the mic LED is on.

06审批Approvals

agent 要权限时，光条橙色闪烁、手柄强双震。用 padpilot run 时，屏幕上的对话框照常出现，✕ 就是回车。不用它时（桌面 app、IDE、直接运行的 agent），hook 最多等你 45 秒：

When the agent asks for permission, the light blinks orange and the controller pulses twice. With padpilot run, the normal dialog appears and ✕ is Enter. Without it (desktop app, IDE, an agent started directly), a hook waits up to 45 seconds for you:

  • ✕ 或 R2 扣到底：批准
  • ○ 或 L2 扣到底：拒绝，拒绝的原因会告诉 agent
  • △：交回屏幕上的对话框
  • 超时或手柄没连：照常显示对话框
  • ✕ or R2 pulled through: approve
  • ○ or L2 pulled through: deny; the agent is told why
  • △: hand it back to the dialog on screen
  • time out, or no controller: the normal dialog appears

这 45 秒里屏幕上不会出现对话框。不想等的话，在设置里把 "hook_approval_timeout_s" 设成 0。有会话在等批准时，焦点自动切过去，所以 ✕ 批准的一定是它。During those 45 seconds there is no dialog on screen. To turn this off, set "hook_approval_timeout_s" to 0. When a session asks, the focus jumps to it, so ✕ always approves the one that is asking.

07Claude 桌面 app（macOS）Claude desktop app (macOS)

没有开着 padpilot run 会话时，按键会变成真正的键盘按下，发给 在最前面的 Claude 桌面 app。别的 app 在前面时什么都不发，光条红闪一下。

When no padpilot run session is open, the buttons become real key presses for the Claude desktop app, only while it is in front. If another app is in front, nothing is sent and the light flashes red.

第一次要给“辅助功能”权限：

The first time, allow Accessibility access:

padpilot desktop    # 系统设置 → 隐私与安全性 → 辅助功能 / System Settings → Privacy & Security → Accessibility
padpilot stop && padpilot desktop   # ok = done

权限给的是 padpilot 后台用的 Python（~/.padpilot/venv）。开着 padpilot run 会话时，按键优先发给那个终端。The permission goes to the Python that padpilot's daemon uses (~/.padpilot/venv). While a padpilot run session is open, the buttons go to that terminal first.

08手柄喇叭Controller speaker

用 USB 连着时，手柄自带的喇叭会在状态变化时响一声：完成 Glass，要批准 Ping，出错 Basso。按住 PS 再按 △ 开 / 关，打开时放一声 Pop。蓝牙连接时没有声音，也从不从 Mac 的扬声器出声。

Over USB, the controller's own speaker plays a cue when the state changes: Glass when done, Ping for approval, Basso on error. Hold PS and press △ to turn them on or off (Pop when on). Over Bluetooth there is no sound, and it never plays through the Mac's speakers.

"sounds": {
  "enabled": true,
  "cues": {"done": "Glass", "permission": "Ping", "error": "Basso"}
}

值可以是 /System/Library/Sounds 里的名字（Basso Blow Bottle Frog Funk Glass Hero Morse Ping Pop Purr Sosumi Submarine Tink）或一个声音文件的路径。A value is a name from /System/Library/Sounds (Basso Blow Bottle Frog Funk Glass Hero Morse Ping Pop Purr Sosumi Submarine Tink) or the path of a sound file.

09练习模式和手柄驾校Practice mode and Pad School

在 Claude Code 里输入 /padpilot:tutorial（或运行 padpilot tutorial），浏览器会打开 手柄驾校：一步一个键，用真手柄、点图或用键盘都能练。

Type /padpilot:tutorial in Claude Code (or run padpilot tutorial) to open Pad School in your browser: one button at a time, with the real controller, by clicking the picture, or with the keyboard.

  • 页面开着就是练习模式：灯和震动照常，按键只在页面里生效，不会发给 Claude。
  • 点页面底下的 「退出练习模式」 或关掉页面就退出；退出后点 「重新进入练习」 接着练。
  • 不开网页也能练：padpilot watch --practice 在终端里显示每个键按了多久、识别成什么。
  • While the page is open you are in practice mode: light and rumble work as usual, but presses only count on the page and never reach Claude.
  • Press “Exit practice” at the bottom of the page, or close it, to leave; “Practise again” brings you back.
  • Without a browser: padpilot watch --practice shows each press, how long it was held and what it counts as.

10设置Settings

只把想改的写进 ~/.padpilot/config.json，它会合并到默认设置上。改完运行 padpilot stop，下次用到时自动用新设置重启。

Put only what you want to change in ~/.padpilot/config.json; it is merged over the defaults. Then run padpilot stop, and the daemon restarts with it the next time it is needed.

{
  "brightness": 0.6,
  "rumble_scale": 0.5,
  "hook_approval_timeout_s": 0,
  "prompt_wheel": ["continue", "run the tests and fix failures", "explain what you just did", "stop and ask me first",
                   "commit", "write tests for this", "summarise the changes", "keep fixing this bug"],
  "mapping": { "triangle": ["text:continue, then run the tests", "act:submit"] }
}

一个键可以映射成A button can map to

  • 功能（推荐）：act:submit act:cancel act:clear_input act:new_session …… 会按目标程序和你的快捷键换算成实际按键。末尾加 ? 表示“没有这个功能就跳过这一步”。
  • 按键：enter esc shift+tab ctrl+<字母>，桌面 app 还能用 cmd+<字母>。
  • 文字：text:…
  • 内置动作：@retry @battery @toggle_lock @choose:1 ……
  • 以上几种组成的列表，按顺序执行。键名也可以是组合（"ps+up"）、长按（"create_hold"）或松开（"mic_up"）。
  • An action (recommended): act:submit act:cancel act:clear_input act:new_session … turned into the right keys for each app and your keybindings. A trailing ? means “skip this step if the app has no such action”.
  • Keys: enter esc shift+tab ctrl+<letter>, and cmd+<letter> in the desktop app.
  • Text: text:…
  • Built-ins: @retry @battery @toggle_lock @choose:1 …
  • A list of any of these, run in order. Button names can also be combos ("ps+up"), holds ("create_hold") or releases ("mic_up").

12它会运行、读取和发送什么What it runs, reads and sends

所有东西都在你自己的电脑上运行。padpilot 没有服务器，不收集使用数据，会话里的内容不会离开这台电脑。

Everything runs on your own computer. padpilot has no server and no telemetry, and nothing about your sessions leaves the machine.

  • Hooks：Claude Code 的事件发生时运行 bin/padpilot hook claude，通过本机 socket 告诉后台程序事件名、会话 id、工作目录和工具名。你发的消息只放在后台程序的内存里，给 R3 用，不写到磁盘。
  • 后台程序：通过 USB 或蓝牙打开手柄，4 小时没有活动自动退出。
  • 唯一一次下载：第一次用时创建 ~/.padpilot/venv，从 PyPI 安装 hidapi==0.15.0。
  • 读：Claude Code 会话记录的末尾（最后一条消息、下一步卡片、上下文用量），你的快捷键设置，Claude app 的听写快捷键。只在内存里用。
  • 写：只写 ~/.padpilot/。日志里只记按键名和状态，输入的文字只记字数。
  • 按键：只发给在最前面的 Claude 桌面 app。麦克风：只查有没有 app 在录音，从不录音。
  • 网页：手柄驾校和这本说明书在 127.0.0.1:8737 上提供，字体从 Google Fonts 加载。
  • Hooks: on Claude Code's events, bin/padpilot hook claude tells the daemon, over a local socket, the event name, session id, working folder and tool name. Your prompt stays in the daemon's memory for R3 and is never written to disk.
  • The daemon opens the controller over USB or Bluetooth and exits after 4 hours without activity.
  • One download: the first time, it creates ~/.padpilot/venv and installs hidapi==0.15.0 from PyPI.
  • Reads: the end of Claude Code's session transcript (last message, next-step card, context used), your keybindings, and the Claude app's dictation shortcut. Kept in memory only.
  • Writes only in ~/.padpilot/. The log holds button names and states; typed text is logged by its length only.
  • Keystrokes go only to the Claude desktop app while it is in front. Microphone: it only asks whether some app is recording, and never records.
  • Pages: Pad School and this manual are served on 127.0.0.1:8737 and load their fonts from Google Fonts.
